# صانع الخطاطات (Khutata)

تطبيق صفحة واحدة يحوّل درسًا مدرسيًا (نصًا ملصوقًا أو صور صفحات) إلى **خطاطة تلخيصية** مع **شرح مبسّط** وأسئلة للمراجعة.

- `khutata.html`: مصدر الصفحة المنشورة داخل Claude (تستعمل قدرة `sample` لاستدعاء Claude دون مفتاح).
- `index.html`: النسخة المستقلة نفسها مع ترويسة HTML كاملة؛ تُفتح في أي متصفح وتطلب مفتاح Anthropic API يُحفظ محليًا في المتصفح.

أنواع الأقسام التي يولدها التطبيق: أركان/مكونات (بطاقات ملونة)، قائمة تحقق، مراحل مرتبة، مقارنة، شواهد (قرآن، حديث، أقوال)، ومفتاح الحفظ.
التعليمات المرسلة إلى Claude تمنع إضافة أي معلومة أو شاهد غير موجود في الدرس، وتطلب نقل الآيات والأحاديث كما وردت حرفيًا.
