# صانع الخطاطات (Khutata)

تطبيق صفحة واحدة يحوّل أي درس إلى **خطاطة تلخيصية** مع **رسوم** و**شرح مبسّط جدًا**.

## المدخلات
- نص ملصوق.
- صور الدرس (اختيار، سحب، لصق Ctrl+V، أو تصوير مباشر من الهاتف).
- ملفات: PDF (نص + صور الصفحات، والممسوحة ضوئيًا تُقرأ كصور)، Word ‏docx (نص + الصور المضمنة)، PowerPoint ‏pptx (نص الشرائح + الصور)، ODT/ODP، TXT/MD/HTML/RTF/CSV.
- الصيغ القديمة (doc, ppt) غير مدعومة: تُحفظ بصيغة docx أو pptx أو PDF.

## المخرجات
- الخطاطة: المفهوم، أقسام (بطاقات، قائمة، مراحل، مقارنة)، الشواهد، مفتاح الحفظ.
- **تمثيلات مرئية** (إلزامية في الرياضيات والفيزياء والكيمياء والعلوم):
  - صيغ بـ LaTeX (MathJax) مع جدول الرموز والوحدات.
  - منحنيات دوال ونقاط قياس يرسمها التطبيق نفسه (محلل تعابير آمن بلا eval).
  - رسوم توضيحية SVG يرسمها Claude (قوى، دارات، بصريات، أشكال هندسية) بعد تنقيتها.
  - جداول، وأشكال مقصوصة من صور الدرس نفسها.
- شرح مبسّط: شرح قصير، تشبيه، أفكار أساسية، مثال محلول خطوة بخطوة (للمواد العلمية)، أخطاء شائعة، أسئلة مراجعة، وقراءة صوتية.
- «اسأل عن الدرس»: أسئلة متابعة حول الخطاطة.
- الترجمة: واجهة بالعربية/الفرنسية/الإنجليزية، وترجمة الخطاطة نفسها إلى أي من اللغات الثلاث (الآيات والأحاديث تبقى بنصها العربي مع ترجمة المعنى).

## الملفات
- `khutata.html`: مصدر الصفحة المنشورة داخل Claude (قدرة `sample` مع الصور، و`downloads` لحفظ الصورة).
- `index.html`: النسخة نفسها مستقلة؛ تطلب مفتاح Anthropic API يُحفظ في المتصفح فقط.

المكتبات تُحمَّل عند الحاجة فقط من cdn.jsdelivr.net: pdf.js 3.11.174، mammoth 1.6.0، JSZip 3.10.1، MathJax 3.2.2، html2canvas 1.4.1.
