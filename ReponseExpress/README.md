# Réponse Express

Le plus direct possible : on donne un devoir (photo, PDF ou texte), on reçoit une feuille de réponses.

- **Pour chaque question :** la réponse en une ligne, puis la méthode la plus simple en 20 mots au plus.
- **Visuel seulement si la réponse en est un :** construction, tableau, courbe ou formule.
- **Interface :** FR / AR / EN ; modèle Haiku 5.5 par défaut, avec Sonnet ou Opus au choix et un réglage d'effort.
- **Outils :** copie de toutes les réponses ; le dernier devoir est gardé dans le navigateur.

Fichiers :
- `reponse-express.html` : page publiée dans Claude.
- `index.html` : version autonome avec clé Anthropic API.
